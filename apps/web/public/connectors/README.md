# Connector glyphs

Locally bundled Simple Icons SVGs (Figma adapted to its multicolor mark) (CC0-1.0; see LICENSE.md), downloaded 20 October 2026:
- https://github.com/simple-icons/simple-icons/blob/develop/icons/figma.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/github.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/coolify.svg

Coolify uses its purple brand color; GitHub retains its standard dark mark.
These decorative examples label navigation, not availability or connected accounts.
The browser loads only these local assets; no third-party icon service is contacted.
